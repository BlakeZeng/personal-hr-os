# Blake1 · SkillOS coordinator

**Draft, Employee Lifecycle Preview.** Read the [request](../../../Context/Guides/Lifecycle%20Practice%20Inputs/Request.md), actual user authority, [role index](../../../Role%20Index.md) and [lifecycle pilot](../../../Context/Guides/Lifecycle%20Pilot.md). Establish the endpoint, accountable handler, source owners and intended receiver.

1. Select the [employee lifecycle specialist](../employee-lifecycle-record-preparation/SKILL.md) in this private workspace. Brief it with the exact case ID, request, rules, event and reference sources, permitted output paths and expected handover.
2. Use the [Case Index](../../../Work/Case%20Index.md) to find or register one canonical record. A missing or conflicting registration returns to its owner. Preserve the original identity, earlier findings and named owner actions on a repeat or correction.
3. Reopen the saved case and handover. Verify source versions, all rows, the decision for every event, each holder and next owner, receiving stage and consistency with the request. If an affected step lacks evidence, return it to the source or decision owner.
4. Give the user a clickable link to the reopened handover in the installed folder and its workspace-relative path. Use an absolute Markdown link target enclosed in angle brackets when the folder name contains spaces. Summarise which events are ready for HR review and which need correction. A draft remains prepared until the designated receiver supplies applicable dated evidence. The user authorises local work. A broader action requires its destination owner's permission.
