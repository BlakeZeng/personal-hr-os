# Tag bank

Draft neutral vocabulary. These labels classify work; they do not establish sources, readiness or permission. Confirm local business workflow/team/organisation labels instead of importing old values.

| Field | Values or treatment |
| --- | --- |
| Status | PENDING, WAIT, DONE, HOLD, CANCELLED |
| Priority | Emergency, Important, Routine |
| Type | Task, Project |
| Task kind | Case, Cycle, Deliverable; Not applicable for Project |
| Pillar | SSC, HRBP, COE as contribution/registration views; confirm any local identifier aliases |
| Brand | Owner-confirmed local label or Not applicable |
| Function | Owner-confirmed business function; do not infer implemented capability |
| Workflow | Confirmed local workflow or Not confirmed |
| PIC team | Confirmed accountable team or Not confirmed |
| Activity | Relevant confirmed activity or Not applicable |
| Reference status | Draft, Approved, Superseded, Withdrawn |

PENDING identifies an internal next action; WAIT identifies a named external event/response; DONE means the agreed scope and checks are complete; HOLD requires an explicit deferral/condition; CANCELLED retains the withdrawal reason. None of these labels creates automatic monitoring.
